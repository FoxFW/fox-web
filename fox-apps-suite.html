Chapter 1

About the Suite

This is the full set of custom Fox apps built for FoxFW2.0, packaged separately from the firmware itself so each app can be installed on its own, built independently, or dropped straight onto an SD card without a full firmware flash.

All of these apps live in the main FoxFW2.0 repository under applications/fox/. The Fox_Apps repository is a standalone export of that same source, plus the compiled .fap files and the SD card resources each app needs at runtime.

Chapter 2

What Makes FoxFW Different

Two things in this suite are exclusive to the Fox ecosystem and aren't found in any other Flipper Zero firmware or app collection:

  • Fox Update Downloader is the only on-device update downloader for Flipper Zero. Every other firmware requires a PC, qFlipper, or a companion phone app to install an update. Fox Update Downloader checks GitHub directly from the Flipper itself, over WiFi via a wired ESP32, compares versions, downloads the matching release for your board, and installs it — no computer involved at any point. It covers both FoxFW2.0 itself and Fox ESP32 Firmware.
  • Fox Chameleon is a Fox-exclusive app. No other custom firmware or app suite ships a BLE bridge between the Flipper and a Chameleon Ultra with a built-in key dictionary for known tag keys.

Chapter 3

Ported Apps ("Fox Edition")

CSIght and TagTinker aren't originally Fox apps — they're other developers' open-source Flipper apps, forked and rewired to run over the same ESP32 wiring and Fox ESP32 Firmware as the rest of this suite instead of needing separate hardware or their own flash. Both carry "(Fox Edition)" in the app name so nobody mistakes them for the unmodified original.

  • CSIght (Fox Edition) originally shipped its own standalone ESP32 firmware plus a built-in USB flashing tool to put it on a bare board. Fox Edition removes that flashing tool entirely and rewrites the Flipper-side UART layer to speak Fox's own protocol instead, so CSI motion/vitals/mesh sensing runs on the exact same ESP32 that's already flashed with Fox ESP32 Firmware for everything else in this suite — no second board.
  • TagTinker (Fox Edition) keeps the original's ESL reading/writing and IR broadcast features untouched. What's new is a WiFi Plugins menu, added by wiring TagTinker into Fox ESP32 Firmware's WiFi bridge — plugins run server-side and stream a rendered image back down to the tag. No ESP32 wired up just means that one menu is unavailable; everything else in the app works the same as it always did.

What's in This Repo

FolderContents
applications_user Full source for every Fox app — one subfolder per app, each buildable with fbt against a FoxFW2.0 (or compatible Flipper firmware) source tree.
FAP_FILES Compiled .fap binaries, sorted into one subfolder per firmware (FoxFW, ARF, Stock, Unleashed, Momentum) since a .fap built against one firmware isn't guaranteed to load on another. Copy the .fap matching whatever firmware your Flipper is running straight to /ext/apps/<category>/ on its SD card.

None of these apps need a full firmware update to install or run. Download the .fap matching your firmware below, copy it to your SD card's apps folder, copy the contents of SD_CARD onto your SD card root if the app needs it (see SD Card Resources), and launch the app from the Flipper's Apps menu.

Chapter 6

ESP32 Companion Suite

Every app below talks to a separate ESP32 dev board wired to the Flipper's GPIO header, running a companion firmware called Fox ESP32 Firmware. None of them work standalone — they need that board wired up and flashed first (Fox ESP32 Flasher can do the flashing step from the Flipper itself).

AppKey capabilities
Fox ESP32 CommanderWiFi menu (network scan, saved credentials, recon/attack toggles), BLE menu (device scan, tag detection), HTTP menu (HTTP/WebSocket bridge), Scripts menu (FoxScript automation engine), Tags menu, a raw message/terminal view, and connection settings shared across the rest of the suite.
Fox ESP32 DetectorSingle-purpose diagnostic — sweeps every GPIO pin pair and baud rate looking for an ESP-AT-compatible response, reports what it finds.
Fox ESP32 TerminalLive streaming console view, quick single-line command send, session log list and viewer, logs written to /ext/apps_data/fox_esp32_terminal per session.
Fox ESP32 FlasherGuided flow: connect, auto-detect chip (ESP32 / S2 / S3 / C3 / C5 / C6), pick firmware files, erase/prepare, flash with a progress view, result screen, plus a raw terminal view for manual commands. Needs the per-chip bootloader/firmware/partition binaries from SD_CARD/apps_data/fox_esp32_flasher.
Fox File DownloaderFour menus off a shared connection: File Download (URL) for direct HTTP/HTTPS downloads with byte-range resume, App Catalog for browsing and installing straight from catalog.flipperzero.one, My Apps for uninstalling anything already on the SD card, and GitHub Repos for pulling a .fap release straight off a repo. A Download.txt queue file lets you line up several URLs at once and let it work through them unattended.
Fox Update DownloaderReads GitHub releases (version comparison, changelog), downloads the matching board's update package over the ESP32 bridge, verifies it, and hands off to the installer — covers both FoxFW itself and Fox ESP32 Firmware. Downloads are resumable, and a downloaded package is validated before install. A Download Settings screen lets you set the UART baud rate, retry attempts, per-chunk timeout, and whether to automatically step down to a lower baud rate on repeated failures.
Fox ChatConnection settings, a scrollable message list, a detail view for a single message thread, and a compose/send view — all relayed through the ESP32 to a configured Discord channel.
Fox PortalConfigurable captive portal menu, QR code generation for quick join, and consent-based field logging. Serves start.html / finish.html from /ext/apps_data/fox_portal, self-seeding them from the repo copy if missing.
Fox ChameleonBridges BLE commands between the Flipper and a Chameleon Ultra over the ESP32's BLE stack, with a built-in key dictionary for known tag keys.
CSIght (Fox Edition)WiFi CSI radar — motion detection, breathing/heart-rate vitals, and mesh node tracking across multiple ESP-NOW-linked boards, all fed through Fox ESP32 Firmware. Same connect/retry/settings gate as the rest of the suite on startup.

SD Card Resources by App

Most apps need nothing extra on the SD card — the app is entirely self-contained in its .fap. The apps below read files from specific SD card paths at runtime; copy the matching folder from SD_CARD/ in the repo onto your Flipper's SD card root before running them.

AppSD card pathWhat's there
Fox Chill/ext/apps_data/fox_chill/jokes.txt, riddles.txt, fun_facts.txt, statistics.txt, yo_mama.txt — the random content pools.
Fox ESP32 Flasher/ext/apps_data/fox_esp32_flasher/<chip>/bootloader.bin, boot_app0.bin, firmware.bin, partitions.bin per supported chip (esp32, esp32c3, esp32c5, esp32c6, esp32s2, esp32s3).
Fox Portal/ext/apps_data/fox_portal/start.html, finish.html — the portal's landing and confirmation pages. The app will self-seed these from the ESP32 if missing, but they load faster if already present.
Garage Door Remote/ext/apps_assets/garage_door_remote/encrypted, vag — the keystore files used for rolling-code key derivation.

Everything else — CSIght, Fox Chameleon, Fox Chat, Fox ESP32 Commander, Fox ESP32 Detector, Fox File Downloader, Fox RF Jammer, Fox Update Downloader, Frequency Analyzer, Modulation Analyzer, SubGHz RAW Edit, and TagTinker — runs with just the .fap copied over, no SD card folder required.

Chapter 11

Building the .fap Files Yourself

The .fap files linked above are prebuilt, but if you want to build any of them yourself:

  1. Copy the app folder(s) you want from applications_user in the Fox_Apps repository into the applications_user folder in your firmware's own root directory (e.g. <your firmware root>\applications_user\fox_chill). Fox Chill and Fox ESP32 Flasher have a _COMPATIBLE-suffixed folder (fox_chill_COMPATIBLE, fox_esp32_flasher_COMPATIBLE) — use that version if you're building for anything other than Fox Firmware.
  2. From your firmware's root, run fbt.cmd build APPSRC=<app folder name> (or fbt.cmd launch APPSRC=<app folder name> to build and push it straight to a connected Flipper). The compiled .fap is named after the app's app ID, which for a few apps doesn't match its folder name: Fox File Browser's folder is fox_file_browser but its app ID is ffb; Garage Door Remote's folder is subghz_gdr but its app ID is garage_door_remote; CSIght's folder is CSIght-FoxEdition but its app ID is csight; TagTinker's folder is TagTinker_FoxEdition but its app ID is tagtinker.
If you're running Fox Firmware, don't copy these apps into applications_user — they're already built into the firmware itself under applications/fox, and adding them to applications_user as well will create duplicate app ID declarations and break the build.
Don't want to set up fbt locally at all? The FAP Compiler does this same build against FoxFW v2.0 for any app on GitHub — paste a repo URL, no local toolchain needed.
