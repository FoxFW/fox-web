The gray strip along the edges is locked on every FoxFW wallpaper — the device draws its live status icons over that area, so anything painted there is never visible on the actual screen. You can only draw in the open white area, same as every FoxFW wallpaper ships with.
Show Live on Device
Streams your drawing to the Flipper's screen in real time. Requires a connected device.

Saving
?
Download
Works with no Flipper connected — saves an .xbm file to your computer. Copy it into the wallpapers folder on the root of your SD card (path: /ext/wallpapers/), then pick it under Fox Settings → Custom Wallpaper on the device.

Save to Flipper SD Card
Saves into the wallpapers folder on the connected Flipper's SD card and sets it as the active Custom Wallpaper. Existing wallpapers are kept — if the name is already taken, a number is added automatically. Requires a connected device.

⚠ Save to Flipper SD Card?

This saves your current drawing into the wallpapers folder on this Flipper's SD card and sets it as the active Custom Wallpaper, turning Custom Wallpaper on if it's currently off. Existing wallpapers are kept — if the name is already taken, a number is added automatically.
